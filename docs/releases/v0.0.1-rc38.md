# v0.0.1-rc38

Deterministic malware deobfuscation, Office/OLE–VBA static analysis, and a
qualified six-sample malware corpus — all static, sandboxed, and network-denied.

Qualified production code: `7da19f9e944a740b1ac9be7be37a88f7cdfc98d5`

This release consolidates the post-rc37 ANALYSIS corpus arc (#260 through the
`execute_analysis` evidence-kind fix) into a documented, qualified release
candidate. No model, controller, KV, prompt, or report-architecture change is
made by the release commit itself; it adds this note and the AGENTS.md entry.

## Highlights

### Deterministic deobfuscation (analysis correctness)
- Decode, before the model reasons, the obfuscation families whose output the
  bytes already determine, recording each decoded stage as evidence with exact
  provenance (input bytes, rule, parameters, output digest). Nothing is executed.
- Families now supported deterministically, each exercised by a frozen corpus
  sample: JScript/PowerShell numeric-XOR; VBScript/PowerShell `Chr(n − const)`
  offset loops; JavaScript `String.fromCharCode` over constant arithmetic;
  `javascript-obfuscator` string-array ProgID folding (base64/RC4 helpers);
  and the VBA byte-array offset + `StrReverse`/`Replace`/`Split` command decoder.
- Every decoder is fail-closed: an ambiguous, reassigned, dynamic, or
  out-of-range construct is refused rather than guessed, and the recovered value
  flows through the existing canonical-indicator machinery (a decoded URL is an
  indicator, never fetched).

### Office / OLE–VBA support
- Recognise OLE2/CFB Microsoft Office documents with a bounded, pure-Python
  reader; decompress the embedded VBA project (MS-OVBA) without executing any
  macro or invoking any application; expose each module's exact source as
  provenance-backed evidence.
- Mark standard macro entrypoints (`Document_Open`, `AutoOpen`, `Workbook_Open`,
  and the small qualified Word/Excel core set) as Office auto-execution event
  handlers when the module and host context prove that semantics — a static
  relationship, not a claim that the document was opened or the macro ran.

### Evidence / reporting
- A sandboxed `execute_analysis` result is labelled `analysis_action`, never
  `fetch`: its observation leads with a `status:` line that a content heuristic
  had read as a network fetch. Provenance fidelity only — identity, admission,
  indicators, and network policy are unchanged.
- The deterministic report appendix renders recovered facts (indicators,
  decoded transform stages, extracted VBA modules, Office event relationships)
  so an authoritative fact survives even when model prose is selective.

### Safety
- Outbound network retrieval is denied during autonomous static ANALYSIS; the
  sandbox runs each action with no network on a read-only copy of the artifact.
- Hostile OLE/VBA parsing is bounded and fail-closed; the VBA evaluators import
  no execution/eval primitive and fold only their own whitelisted representation
  of inert text.

### Large-source support
- An oversized source (beyond the context window) gets a deterministic
  structural bootstrap so PLAN is not blind, and the run reads bounded ranges of
  the exact source rather than terminating silently.

## Performance (one CPU-only system; see docs/benchmarks and the multisample bench)
Corpus aggregate over six fresh autonomous runs: 79 model calls, 24 actions,
163,891 prompt tokens, 69,615 cached (42.5% KV reuse), 21,317 generated. Phase
cost by evaluated tokens: FINISH > REPORT > PLAN > STEP > COVER; REPORT is the
largest uncached recurring consumer. Figures are measurements on one reference
NUC, not universal speed claims; absolute wall time on a contended host is not a
comparable number.

## Known limitations
- Static only: no malware, macro, or decoded script is executed; no remote
  payload is retrieved; there is no dynamic sandbox.
- Unsupported obfuscation families fail closed (not decoded) rather than guessed.
- The Office auto-execution taxonomy is intentionally limited to the qualified
  Word/Excel core events.
- A model run may reach its action/call ceiling on a complex artifact while the
  deterministic evidence is already complete; the grounded report still carries
  the deterministic facts.
- CPU-only; performance is dominated materially by model inference.
