# v0.0.1-rc34

Deterministic context management, evidence-grounded finalization, two more
verified native models, and exact multi-turn chat correctness.

Qualified production code: `dbc63cbc638ea6ea3a9d4ce4020547eea78050b0`

## Highlights

- Add a deterministic context manager that decides admission before every model
  call, so a turn that cannot fit is refused predictably instead of failing
  mid-inference.
- Answer from verified evidence when the session is full or otherwise cannot
  carry the conversation, keeping the final answer grounded in what was actually
  read rather than in a truncated window.
- Render cited evidence byte-exactly in final answers, and preserve the complete
  document evidence handoff across the tool boundary.
- Honor explicit full-document output budgets, and allow structured reads that
  earlier releases refused under negative mutation wording or for small files.
- Qualify Ornith 1.5 35B-A3B as a verified native model, and add the verified
  Qwen3.8-27B profile.
- Reuse KV by strict append-only continuation: when the resident sequence is a
  token-exact prefix of the next prompt, only the new suffix is prefilled. No
  partial cache removal is attempted, which keeps the path safe on hybrid and
  iSWA caches that legitimately refuse it.
- Report why a strict-append continuation was refused, through bounded
  first-miss diagnostics that record the mismatch without logging prompt text.
- Read every metadata key the verified profiles compare, so a model no longer
  appears as both missing and available in discovery.
- Keep the user turn ahead of the assistant in rebuilt windows, fixing a
  multi-turn failure where the second turn could be rejected before inference.
- Keep measured token usage when an attempt fails and is retried; totals are
  reported as partial rather than discarded.
- Check that a stored session is resumable before it becomes the active chat, so
  a structurally invalid saved session is rejected at load instead of failing
  later.
- Stop counting a deliberate route stop as a failed call. The route phase ends
  its own stream early once output is clearly conversational prose; that is an
  optimisation, not a backend failure, and ordinary turns no longer report a
  failed attempt that never happened.
- Correlate idless Qwen tool calls, reset independent static sessions, and honor
  profile history serialization on external servers.
- Terminal fixes: render Markdown inline code, and restore the prompt after
  direct slash commands and slash answers.

RC34 contains squash merges from PRs #191 through #218. RC33 remains the
published predecessor.

## Limits

- Validation figures are specific to the documented hardware, model files,
  backend build, and workloads.
- Ordinary conversational chat does not currently reuse route KV between turns.
  The route and final phases build different prompt families that share only a
  few leading tokens, so each call prefills from cold. This is expected under the
  current prompt topology and is not a cache defect.
- Strict append-only continuation applies when the next prompt is a token-exact
  extension of the resident sequence; anything less falls back to a cold prefill.
- When an attempt is stopped before its usage event arrives, token totals are
  reported as partial. Server-side accounting for those attempts is not complete.
