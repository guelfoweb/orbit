# v0.0.1-rc26

Verified native Qwen 3.6 support, model-specific route-prefix reuse, Gemma
final-projection fixes, and complete CLI token observability.

## Summary

- Add native support for the exact verified Qwen 3.6 35B-A3B Q4_K_M profile.
- Render the official embedded Qwen template through a revision-bound native
  bridge and keep reasoning, visible content, and tool calls separate.
- Enable a Qwen-specific 768-token route-prefix checkpoint for the verified
  profile, with an immediate kill switch.
- Preserve complete Gemma tool evidence in bounded final projections so
  directory listings stop cleanly and mutation answers report the completed
  change and verification.
- Report exact completed-call token totals per turn and per interactive
  session without adding model calls or prompt tokens.

## Qwen 3.6 Profile

The supported artifact is exactly `Qwen3.6-35B-A3B-Q4_K_M.gguf` under profile
`orbit-qwen36-native-v1`. Authorization uses verified GGUF architecture, model,
tokenizer, quantization, and embedded-template metadata. The reviewed template
SHA-256 is
`e84f32a23fdda27689f868aa4a1a5621f41133e51a48d7f3efcbea2839574259`.
Filename matching alone never enables the profile.

The native Qwen bridge renders the official embedded template, applies
`enable_thinking` explicitly, serializes Qwen tool declarations, tool calls,
tool results, and assistant history, and returns reasoning separately from
visible content. Thinking is forced off in route, tool, document-search, and
other structured phases. Reasoning never reaches route or canonical tool-call
parsers.

Qwen chat, multi-turn history, local tool calling, failed-command reporting,
post-tool finalization, inert JSON/XML/Markdown handling, timeout,
cancellation, reset, and restart passed the real-model validation matrix.
Canonical validation, deterministic formal healing, permissions, no-mutation
safety, repeated-call protection, and executors remain shared runtime
authorities.

## Qwen Route Prefix

The exact verified profile enables a process-local route checkpoint by
default. The invariant route prefix contains 810 tokens; Orbit captures the
complete hybrid sequence state at the 768-token batch-aligned boundary without
padding. The checkpoint is 81,608,684 bytes and is bound to the model,
quantization, context, profile, template, tokenizer, schema, backend build, and
process.

Cold, explicitly segmented, captured, and restored probes produced
byte-identical logits with maximum absolute difference `0.0`, identical next
tokens, top candidates, route outputs, tool names, typed arguments, and finish
reasons. In the measured 11-route comparison, reuse reduced evaluated prompt
tokens from 9,094 to 1,414 and restored 7,680 prefix tokens with zero fallback.
Measured prefill total changed from 273.94 seconds to 43.72 seconds and wall
total from 287.78 seconds to 57.87 seconds. These CPU timings are descriptive,
not a portable or deterministic performance guarantee.

`ORBIT_QWEN_ROUTE_PREFIX_REUSE=0` is the immediate kill switch. Invalid values
disable reuse safely. Cancel, timeout, reset, restart, context change, identity
change, and restore failure invalidate the checkpoint or fall back to a full
prefill without sharing partial state.

## Gemma Finalization

The Gemma production corpus exposed two strict final-answer failures after the
Qwen merge: one complete directory listing reached its final budget, and one
successful, verified file mutation did not state the completed change clearly.
The retained fix preserves bounded complete tool evidence and mutation plus
verification facts in the final projection. The model still authors the final
answer; no tool, retry, budget, parser, or executor behavior changed.

The exact directory-listing and existing-file mutation scenarios now finish
with `stop`, preserve the requested evidence, and report the completed result.
The complete Gemma corpus remains 12/12 strict PASS.

## Token Observability

The CLI footer omits the model name and reports per-turn totals across every
completed backend call: prompt input, evaluated prefill, cached prefix, decoded
output, and call count. Cached tokens are not counted as evaluated work.
`/status` and normal session exit report session totals; explicit session reset
clears them.

Timeout and cancellation attempts are represented without inventing usage the
backend did not return. If an interrupted call has no authoritative metrics,
the aggregate is marked unavailable and the failed attempt remains visible.
Observer failures cannot change inference results or replace backend errors.
The footer adds no prompt tokens, model call, route, tool, or checkpoint work.

## Limits

- Qwen support is restricted to the exact verified 35B-A3B Q4_K_M profile.
- Other Qwen templates, quantizations, and variants require separate
  qualification.
- Qwen MTP and Qwen multimodal input are not supported.
- Qwen route checkpoints are process-local and are never portable or shared
  with Gemma, another profile, another context, or MTP.
- Thinking remains disabled in structured phases. User-visible thinking can
  consume substantial decode budget and remains explicit.
- CPU timings depend on hardware, thermals, prompts, output length, and process
  state; no universal speedup is claimed.
