## Qwen 3.6 Shell Prefix

The exact verified `orbit-qwen36-native-v1` profile keeps one separate
process-local checkpoint for tools-on, thinking-off calls in the normal
`tool_call` phase with exactly the reviewed single `exec_shell_full_command`
schema. Other tools, multiple-tool schemas, retries, artifact verification,
artifact content, final generation, other Qwen profiles, Qwen3-Coder, and Gemma
remain ineligible.

The checkpoint captures complete Qwen 3.6 hybrid sequence state at the
unpadded 384-token boundary inside the 439-token invariant shell prefix. Its
identity is `qwen36-shell-tool-prefix-v1` and binds the verified model/GGUF,
tokenizer, template, shell schema, system policy, rendered and token hashes,
native build, context, batch, ubatch, threads, and checkpoint version.

Capture and restore use the existing native sequence-state primitives. A
checkpoint-local lock and lifecycle epoch prevent cancellation, reset, reload,
or close from publishing stale state. Invalid restore state is discarded before
use and permits one cold fallback without a retry loop. The Qwen route and
shell checkpoints retain separate identities, counters, and storage.

Reuse is enabled by default for only this qualified path. Disable the shell
checkpoint independently with:

```bash
ORBIT_QWEN36_SHELL_TOOL_PREFIX_REUSE=0 orbit server \
  --model models/ggml-org--Qwen3.6-35B-A3B-GGUF/Qwen3.6-35B-A3B-Q4_K_M.gguf
```

Qualification measured a 73,736,684-byte checkpoint. Cold, segmented, and
restored logits were byte-identical with maximum absolute difference `0.0`.
The reviewed process-isolated runs reduced `pwd_final` from 42.10 to 30.50
seconds and existing-file modification from 277.70 to 181.47 seconds. Each warm
shell restore avoided 384 evaluated tokens. Twenty restores showed no linear
RSS growth. These CPU measurements are descriptive and hardware-dependent.

## Limits

- Shell-prefix reuse is limited to the exact verified profile, template,
  configuration, and single shell-tool schema.
- The roughly 70.3 MiB checkpoint is process-local and is not prewarmed.
- Reset, reload, cancellation, close, or identity changes invalidate the shell
  checkpoint; the next eligible path captures cold.
- Timings are single-host CPU qualification evidence, not performance
  guarantees.
- RC30 Qualification Harness, native capability-discovery, and full-document
  behavior remain unchanged.
